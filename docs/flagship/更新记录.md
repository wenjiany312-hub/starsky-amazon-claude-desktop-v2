# Claude Desktop 旗舰版更新记录

## 3.1.4 · 2026-10-13 · Windows 广告桌面入口

- 安装或更新 Claude旗舰版后自动创建彩色「启动星空广告终端（Claude）」与「停止星空广告终端（Claude）」快捷方式。
- 启动使用图形运行环境，不弹命令行黑窗口；首次准备广告引擎，已有店铺接入直接进入综合看板，未接入进入向导。旧数据和配置保留。
- 快捷方式读取当前 Claude 安装记录，插件升级后继续使用；与 Codex 图标及入口配置分开。较新的兼容广告引擎不会被降级；陌生端口占用不强制关闭。
- 停止前核对进程身份，停止失败明确提示；不改变本人审核广告写入规则。
- Claude 自身 Sonnet／Opus／Haiku 方案及更新器签名回退规则保留。引擎业务载荷仍为 alpha.20；不迁入 Codex 模型或 Codex MCP 检测方案。运营版和 Codex 本次不推送，Mac 沿用原启动器。

## 3.1.3 · 2026-10-12

包含运营版 3.0.8 的 S1 产品开发决策透视：组件图片与货源逐项对应、目标利润反推售价、缺失费用保留为空、厂家前置清单、带证据的拿样建议、同源 Markdown/HTML 报告同步与导航。历史正文、备注和关键词保留；“仅 S1”不自动进入 S2，交付、拿样建议与采购授权独立判断。

保留 Claude 自身 Sonnet／Opus／Haiku 推荐路由及旗舰 AI 智能广告终端，引擎 alpha.20；真实 Haiku 型号派发仍需对应宿主验收，不作跨模型质量或额度节省承诺。

保留 3.1.2 更新器限流修复：GitHub API 失败时通过固定公开目录定位，随后下载并验签旗舰更新清单；公开目录不作为更新授权或版本结论。两路失败时显示原因并保留当前版本。旧入口持续限流时，下载新版完整包运行「安装与更新」，沿用现有会员授权。

运行 **「检查新版」或「安装与更新」**，完成后重开 Claude Desktop，在 Code 页签新建本地会话。会员有效期以授权为准；Mac、B/C 电脑与实际店铺业务需分别验收。
