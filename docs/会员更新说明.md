# Claude Desktop 正式版 · 年度会员更新与续期

仅提供 365 天（1 年）年度会员。按北京时间计算，包含签发当天，至授权到期日当天结束；具体日期以作者签发结果为准。

## 更新操作

下载本仓库最新的对应平台安装包，完整解压后运行 **安装与更新**，或在已安装入口运行 **检查新版**。有效年度会员通过会员更新凭证获取新版，无需逐版申请 Key。完成后回到 Claude Desktop 的 Code 页签，新开本地会话输入「启动星空」。当前发行不提供 Git Marketplace 一键升级入口。

Claude Desktop「Customize → Your plugins」里的 Update 按钮当前不代表本产品有新版，请以「检查新版」为准。

新版必须由作者向本正式版通道发布，并为有效会员提供对应档位的更新凭证。首次安装前仍需取得本机 Key；后续有效期内更新无需逐版换 Key。下载文件和成功解锁是不同步骤，以新会话实际加载的版本为准。

## 到期、续期与设备绑定

到期后已安装内容保留，后续新版本需续期。续期由作者延长原设备的会员权益并同步更新凭证；一机一码，不支持更换电脑；不能沿用另一台电脑的码。

## 正式版与测试版

本仓只发布付费正式版；测试版的 Key、登记表和发行通道独立。测试授权不包含正式版，不能因为测试通道更新或停止维护而自动转为正式会员。

## 购买与设备规则

**一机一码，不支持更换设备，多台电脑需分别购买；购买后不接受退款，请确认需求后再购买；但如果是产品本身无法按说明正常使用等质量问题，作者会协助解决，不受这一条限制。** 购买前请确认产品、版本档、系统环境与所绑定的电脑。

详见 [使用条款](使用条款.md)。

## 更新失败

先确认产品、版本档、当前授权日期与网络状态。只拉取到文件但解锁失败时，保留旧版本和业务资料，将已脱敏错误发给作者；不要发送完整 Key、配置密钥或店铺数据。没有可确认的新版本时继续使用当前安装版本。


## 2026-10-17 更新说明

# Claude Desktop 正式版：更新与老用户迁移

新用户首次完整解压正式安装包，申请并完成本机授权后运行「安装与更新」。新版安装器会登记 GitHub 更新市场，保留完整技能、三个知识库连接器和三个子代理。

## 以后如何更新

打开 **Plugins → Starsky amazon agent → Update**，有新版时按宿主提示更新，然后重开 Claude Desktop、新建会话。

已是最新版时按钮可能置灰；如果本机版本落后而按钮仍灰，先刷新星空市场、重开客户端，并核对是否仍登记为本地目录。不能仅凭灰色按钮断言已是最新。

本市场默认启用自动刷新；实际检查时机由 Claude 宿主控制。原生 command 来源要求内置 Claude Code 至少 **2.1.229**，不满足时先升级 Claude Desktop。第三方模型/API 不决定市场更新权限。

## 旧本地安装只需迁移一次

1. 完整解压适合系统的 **Claude 原生更新适配包 1.0.3**。
2. **请在系统终端运行，不要让 Claude 代为运行。** Windows 运行「开启原生更新.bat」；Mac 运行「开启原生更新.command」。Mac 无法双击时，在终端输入 `bash `，拖入该文件再回车。
3. 按提示允许本机安装适配命令。适配器会校验签名、现有授权和目标发行，并将同名 `starskyclaude` 市场改为 GitHub 来源。不需要先删除插件。
4. 完全退出并重开 Claude Desktop，在新会话核对版本。插件页应只有一个星空；知识库连接器三个、子代理三个。
5. 以后使用插件页 Update，不需要逐版下载安装包或更换授权码。

授权、模型/API、S5 接入配置、产品资料和广告终端数据保留。旧版本和迁移登记备份保留供恢复；失败时按提示处理，不自行删除这些目录。旧缓存暂时保留，清理须另行提示并由用户确认。

本适配包不签发或续期会员授权。有效会员沿用现有凭证；缺授权时先联系作者办理本机授权。会员到期不锁已安装内容，新版校验未通过不会替换当前完整插件，续费后再更新。

下载：[原生更新适配包 1.0.3](https://github.com/wenjiany312-hub/starsky-amazon-claude-desktop-v2/releases/tag/claude-native-update-v1.0.3)。C 电脑已反馈迁移成功，授权、知识库与原有数据保留。1.0.3 修复 Mac 启动脚本换行，并明确系统终端确认要求；下一次真实版本的原生 Update 仍待实测。
